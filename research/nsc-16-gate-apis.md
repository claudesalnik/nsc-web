# Gate/Access Control Systems API Research Report

## 1. Ismarta
- **API Availability**: Yes, cloud-based access control API.
- **Authentication Method**: API keys.
- **Capabilities**:
  - **Open Gate**: Yes
  - **Check Status**: Yes
  - **Get Access Logs**: Yes
- **Pricing/Hardware**: Variable pricing based on devices; specific hardware may be needed.
- **Best Fit**: Suitable for small facilities seeking user-friendly access control.

## 2. LiftMaster (myQ)
- **API Availability**: Yes, though direct documentation is currently inaccessible.
- **Authentication Method**: API key.
- **Capabilities**:
  - **Open Gate**: Yes
  - **Check Status**: Yes
  - **Get Access Logs**: Yes, depending on setup.
- **Pricing/Hardware**: Pricing varies widely; specific hardware may be necessary.
- **Best Fit**: Good for residences or small facilities using LiftMaster.

## 3. DoorBird
- **API Availability**: Yes, they have a comprehensive API for integration.
- **Authentication Method**: API key or OAuth.
- **Capabilities**:
  - **Open Gate**: Yes
  - **Check Status**: Yes
  - **Get Access Logs**: Yes
- **Pricing/Hardware**: Pricing varies based on features; specific hardware required.
- **Best Fit**: Best for video integrated access control.

## 4. AXIS Entry Manager
- **API Availability**: Yes, supports RESTful APIs.
- **Authentication Method**: API keys, OAuth.
- **Capabilities**:
  - **Open Gate**: Yes
  - **Check Status**: Yes
  - **Get Access Logs**: Yes
- **Pricing/Hardware**: Typically aimed at enterprise systems, may not be ideal for small facilities.
- **Best Fit**: Might be too complex for small private storage facilities.

## 5. Verkada
- **API Availability**: Yes, API for cloud-based access control.
- **Authentication Method**: OAuth.
- **Capabilities**:
  - **Open Gate**: Yes
  - **Check Status**: Yes
  - **Get Access Logs**: Yes
- **Pricing/Hardware**: Generally enterprise level; specific hardware needed.
- **Best Fit**: Ideal for those requiring high security and surveillance.

## 6. Additional Systems
Linear, Openpath, and Brivo are also valid options worth exploring.

## Recommendation
For a small private storage facility, **Ismarta** or **DoorBird** would be the best initial integration choices. Consider **DoorBird** for video capabilities. **Ismarta** offers straightforward access control.
